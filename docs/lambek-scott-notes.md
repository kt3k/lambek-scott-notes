## 1. 本書の位置づけ

数学の基礎をめぐる **数理論理学** と **圏論** の2つの視点を統合・調和（reconciliation）する古典的名著。

- **Part I** — 型付きλ計算（高階論理の一形式）と **デカルト閉圏 (CCC)** が本質的に同じ（Curry–Howard–Lambek 対応の "Lambek" 部分）。
- **Part II** — 直観主義型理論と **トポス (topos)** が本質的に等価。
- **Part III** — 帰納的関数。

圏論の入門も含み、ほぼ自己完結的。各節末に演習。

## 2. トポスは特殊な圏

圏 𝓔 が（初等）トポスであるとは：

1. 有限極限を持つ（終対象 1、積、引き戻し）
2. **デカルト閉**（指数対象 Bᴬ がある＝関数空間が圏内に存在）
3. **部分対象分類子 Ω を持つ** ← トポス固有の決め手

おおまかに **トポス ＝ デカルト閉圏 ＋ 部分対象分類子 Ω**。Ω を足すと論理（真理値・述語・量化）が圏の内部で展開できる。

例：**Set**, **G-Set**, 層の圏 **Sh(X)**, 前層 **[𝓒ᵒᵖ, Set]** はトポス。**Grp**, **Top** はトポスでない。

トポス＝「集合の圏 Set を一般化した世界」。内部論理は一般に古典論理ではなく**直観主義論理**（Ω がブール代数でなくハイティング代数）。

## 3. Set における true / false と Ω

発想の転換：真理値を先に定義するのではなく、**射と普遍性から true/false が決まる**。

- 終対象 1 ＝ 1点集合 `{∗}`。射 `1 → A` ＝「A の要素を1つ選ぶこと」（global element）。
- Set では `Ω = {真, 偽}`（2点集合）。**`true : 1 → Ω`（∗ ↦ 真）という射**が「真」を指名する。

### 部分対象分類子の普遍性

任意の単射（部分集合）`A ↪ X` に対し、次が**引き戻し (pullback)** になる射 `χ_A : X → Ω` がただ一つ存在する：

```
   A ──────→ 1
   │          │
   │(包含)    │ true
   ↓          ↓
   X ───────→ Ω
       χ_A
```

Set ではこれが「x ∈ A ⟺ χ_A(x) = 真」を意味し、`χ_A` は **A の特性関数**そのもの。

| 集合論的 | 圏論的 |
|---|---|
| 要素 a ∈ A | 射 `1 → A` |
| 真理値「真」 | 射 `true : 1 → Ω` |
| 部分集合 A ⊆ X | 単射 `A ↪ X` |
| 特性関数 χ_A | 射 `χ_A : X → Ω`（pullback で特徴づけ） |

### Ω は同型を除いて一意

Ω は普遍性で定義されるので **同型を除いて一意**。Set では任意の2点集合を選べるが全部標準的に同型。ただし **集合 Ω だけでなく射 `true : 1 → Ω`（どの元が真か）まで指定**して初めて分類子。選び方は理論を変えない。

## 4. 同型な対象は圏論的に区別できない

Set では `|A| = |B| ⟺ A ≅ B`。そして圏論の大原則：**同型な対象は圏の言葉だけでは区別できない**（principle of equivalence）。

- 厳密には射が「同じ」のではなく、同型 φ を固定すると hom 集合が標準的全単射で対応し、入る射・出る射のネットワークが完全に一致する。
- これは Set 固有でなく圏論一般。圏論で書ける性質はすべて**同型不変**。だから終対象・積・Ω 等が「同型を除いて一意」としか言えない。
- 言い換え：Set はその**骨格 (skeleton)** と圏同値。圏 Set が対象について「見ている」のは**基数だけ**。

## 5. type theory を構成する3つのデータ

型理論（言語 𝓛）は **(1) 型 (2) 項 (3) 定理（演繹）** で定まる。

- **型の生成規則**：①`1` ②`Ω` ③`A×B`（積型）④`PA`（冪型＝Ω^A）。
- **(3) 定理** ＝ どの式（＝ Ω 型の項）を「証明可能」とみなすか ＝ 演繹関係 `⊢`。

### 第3データ「定理」の意味

- (1)(2) だけでは**言語**にすぎず「何が書けるか」しか決まらない。(3) で初めて**論理を持った理論**になる。
- 型・項が同じでも定理集合が違えば**別の型理論**（例：排中律を入れる＝古典／入れない＝直観主義）。
- ただし任意の集合ではなく、**論理公理を含み推論規則で閉じている**必要。「公理＋規則」と「定理全体」は情報として等価。
- Part I では「成り立つ等式の集合」だったものが、Part II では「Ω 型の式の `⊢`」に格上げ。

### トポスへの翻訳

| 型理論 | トポス |
|---|---|
| 式 `φ(x)` | 部分対象 `{x:A∣φ} ↪ A` |
| `φ ⊢ ψ` | 部分対象の包含 `{φ} ≤ {ψ}` |
| `⊢ φ` | `{φ} = A`（全体に一致） |

第3データが「どの部分対象が含まれる／一致するか」を決め、「型理論 ↔ トポス」の同値の接着剤になる。

## 6. 基礎論的主張（序論あたり）

著者の立場の正確な姿：

- ✗「圏論ではなく型理論」という**対立図式ではない**。本書の主張は **型理論 ＝ トポス（圏論）** という**統合**。
- △〜◯「集合論を唯一の基礎とする見方」には懐疑的で、**高階直観主義型理論（＝自由トポス）**を基礎の候補に推す。
- Lambek の有名な立場：**自由トポス (free topos)** を、論理主義者・直観主義者・形式主義者のいずれにも受け入れ可能な中立的基礎として提案。構文から構成されるので特定哲学へのコミットが少ない。

### 循環性（メタ理論問題）

「定理全体の集合」を与える時点で集合論的言葉を使っているのでは？という違和感は正しい。応答：

- **対象理論**（基礎に据える型理論）と**メタ理論**（それを語る言語）は別レベル。
- この循環は型理論固有でなく**あらゆる基礎づけ**に起こる（ZF を提示するにも構文・「公理の集合」が要る）。「前提ゼロの基礎」は無限後退で不可能。
- ただし形式体系の定義に必要なメタ理論は**有限・組合せ論的**（PRA 程度）で、基礎づけたい集合論よりはるかに弱い ⟹ **悪循環ではない**。
- 「定理全体」は完成した無限集合（外延的）でなく、**生成的（公理＋規則で閉包＝有限の証明を持つ式）**に与えればよい。platonist 的把握は不要。
- 基礎の価値は「前提ゼロ」でなく**縮減 (reduction)**：巨大で論争的な数学を、小さく明晰な有限的土台へ。

## 7. 自由トポス (free topos) を定義するデータ

2つの等価な与え方。

### (A) 抽象的：始対象として

トポスと**論理射**（1, ×, Ω, P をオンザノーズに保つ関手）の圏 `𝐓𝐨𝐩𝐨𝐬_log` の **始対象**。
任意のトポス 𝓔 に論理射 `𝓕 → 𝓔` が同型を除いてただ一つ存在。「自由」＝「生成元ゼロの自由生成物」。

### (B) 具体的：純粋型理論 𝓛₀ から建てる

3つのデータをすべて**空（最小）**にとる：

| データ | 自由トポス |
|---|---|
| 型 | 基本型を追加しない（`1, Ω` から `×, P` のみで生成） |
| 項 | 定数・関数・関係記号を追加しない |
| 定理 | **固有公理ゼロ**（純粋高階直観主義論理の論理公理だけ） |

構成 `T(𝓛₀)`：
- 対象 ＝ （閉じた）型 A
- 射 `A → B` ＝ 文脈 `x:A` の項 `f(x):B` の、**証明可能な等しさ `⊢` による同値類** `[f]`
- 合成 ＝ 代入、恒等 ＝ 変数項 `[x]`
- トポス構造：終対象 `1`、積 `A×B`、冪 `Bᴬ`、分類子 `Ω` と `true=⊤`

(A) と (B) は一致：固有公理ゼロゆえ任意のトポス 𝓔 への論理射が内部言語経由で一意に決まる。

自由トポスの良い性質（純粋直観主義数学）：
- **disjunction property**：`⊢ φ∨ψ` なら `⊢ φ` か `⊢ ψ`
- **existence property**：`⊢ ∃x.φ(x)` なら、ある項 `t` で `⊢ φ(t)`

「真である ⟹ 構成的証拠がある」。Lambek が基礎に推す理由。

## 8. 演習：∧ : Ω×Ω → Ω を項として導出

論理結合子は原始記号ではなく**項として定義され、固有公理ゼロの純粋論理だけで正しく振る舞う** ⟹ 自由トポスに最初から住む射。

### 使える原始データ（𝓛₀）

- 各型 A の等号述語 `=_A : A×A → Ω`
- 終対象型 `1` と唯一の項 `∗ : 1`
- 積：`⟨a,b⟩`、射影、surjective pairing：`⊢ ⟨a,b⟩=⟨c,d⟩ ⟺ ⊢ a=c かつ ⊢ b=d`
- `λ`、`Ω`
- 構造規則 (†)：φ:Ω について `⊢ φ ⟺ ⊢ (φ =_Ω ⊤)`

`∧, ∨, ⇒, ∀, ∃` はまだ無い。等号・組・Ω から作る（Henkin–Lambek）。

### 定義

```
⊤      :≡  (∗ =_1 ∗) : Ω                            （反射律で ⊢ ⊤）
∧      :≡  λ⟨p,q⟩:Ω×Ω. ( ⟨p,q⟩ =_{Ω×Ω} ⟨⊤,⊤⟩ )
```

直感：「p∧q ＝ 組 ⟨p,q⟩ が ⟨真,真⟩ に等しいこと」。meta の "and" を使わず、等号と組だけで定義。

### 射としての姿

`T(𝓛₀)` で `∧` は文脈付き項の同値類：

```
[ z : Ω×Ω ⊢ (z =_{Ω×Ω} ⟨⊤,⊤⟩) : Ω ]  :  Ω×Ω ⟶ Ω
```

### 検証（補題）

`⊢ (p∧q) =_Ω ⊤  ⟺  ⊢ p=_Ω⊤ かつ ⊢ q=_Ω⊤`

```
p ∧ q  ≡ ( ⟨p,q⟩ =_{Ω×Ω} ⟨⊤,⊤⟩ )           （定義 + β）
⊢ (p∧q)=⊤
 ⟺ ⊢ ⟨p,q⟩ = ⟨⊤,⊤⟩                          （†）
 ⟺ ⊢ p=⊤ かつ ⊢ q=⊤                          （surjective pairing）
 ⟺ ⊢ p   かつ  ⊢ q                            （†）
```

これは論理積の真理値表そのもの。例：`⊤∧⊤`＝`⟨⊤,⊤⟩=⟨⊤,⊤⟩` は反射律で真。

### 要点

どのステップも「論理公理＋等号＋積構造」だけで、**固有公理を一切使わない** ⟹ 射 `[∧] : Ω×Ω → Ω` は自由トポス `T(𝓛₀)` に**最初から存在**。結合子は外から足す構造でなく、すでに住んでいる射。

### 他の結合子（すべて等号から）

| 結合子 | 定義 |
|---|---|
| `⊤` | `∗ =_1 ∗` |
| `p ∧ q` | `⟨p,q⟩ =_{Ω×Ω} ⟨⊤,⊤⟩` |
| `p ⇒ q` | `(p ∧ q) =_Ω p`（meet による順序） |
| `∀x:A. φ` | `{x:A∣φ} =_{PA} {x:A∣⊤}`（部分集合が全体に一致＝部分対象の包含） |
| `⊥, ∨, ∃` | `∀`/`⇒` で二階に定義（impredicative encoding） |

`∀` の「全称 ＝ 部分対象の包含」は §3 の Ω の話と噛み合う。

## 9. 自然数対象 (NNO)：`1` 型と `∗` の役割

「Peano 算術を型理論として定義すると `1` 型と `∗` は何になるか」という問いから整理。

### まず混同に注意

| 同じ記号でも別物 | 正体 |
|---|---|
| 終対象型 `1`（unit type） | 枠組み固有の型。`∗:1` を唯一の項に持つ |
| 自然数の「1」 | `N` 型の項 `s0`。`1→N` の合成。**`1` 型ではない** |

`1` 型 ≠ 数の 1。記号が衝突しているだけ。

### Peano を型理論として「足す」もの

§4 の3つの自由パラメータに Peano 固有のものを入れる（`𝓛₀ + (N,0,s,\text{Peano})`）：

| 自由パラメータ | Peano で足すもの |
|---|---|
| 基本型 | `N`（自然数型） |
| 非論理語彙 | 定数 `0`、後者関数 `s` |
| 固有公理 | Peano/Heyting 算術の公理（＝ NNO の普遍性） |

`1, Ω, ×, P` と原始 term-former（`∗, =, ⟨⟩, …`）は据え置き。`1` も `∗` も**変わらない**。

### `1` と `∗` が効く場所：`0` と数字の住所

§3 の「閉じた項 ↔ `1→A`」より、定数 `0` は `N` の global element：

```
0 : N  （閉じた項）  ⟷  0 : 1 ⟶ N  （global element）
```

数字はすべて `1→N` の射で、共通の定義域が `1`：

```
0,  1 = s0,  2 = ss0,  …,  n = sⁿ0  :  1 ⟶ N
```

- `1` 型 … すべての数字 `1→N` の**定義域**。数字そのものにはならない。
- `∗ : 1` … その定義域の唯一の点（generic point）。`id₁` のまま。

### 圏論的正体：自然数対象 (Natural Numbers Object)

```
1 ──0──→ N ──s──→ N
```

がトポスの **NNO**。普遍性 ＝ 原始再帰：

> 任意の `1 ─x→ A ─f→ A` に対し、`h∘0 = x` かつ `h∘s = f∘h` を満たす射 `h : N → A` が**ただ一つ**存在する。

左端が `1` であることが本質。`1` がないと初期値 `0` の起点や再帰の種 `x:1→A` を射で書けない。**終対象型 `1` は Peano の再帰・帰納の起点を供給する装置**（L&S Part III の主題）。

### 自由トポスとの関係

自由トポス `T(𝓛₀)` は最初から NNO を持つので、`N,0,s` を外から足さなくても自然数は内在する。

- 「`N` を基本型として公理的に足す版」
- 「自由トポスの NNO を使う版」

は別の入口で、L&S は後者（NNO）を本筋にする。

### 補足：`1` 型の別名と「なぜ `1` か」

Peano の文脈では型 `1` と数の `1`（＝`s0`）が記号衝突して紛らわしい。この対象は分野ごとに別名がある：

| 分野 | 呼び名・記号 | 強調点 |
|---|---|---|
| 圏論 / L&S | **終対象 (terminal object)**、`1` | 普遍性「どこからでも射が一意」 |
| 型理論 / PL | **単位型 (unit type)**、`()`, `unit`, `𝟙` | 「自明な値が1つだけの型」 |
| Martin-Löf / HoTT | `𝟙`（空型 `𝟘` と対） | 要素数 |
| 論理（Curry–Howard） | **`⊤`（真, verum）** | ∗ ＝「真の自明な証明」 |

**なぜ圏論は `1` と呼ぶか** ＝ Set の対象を数のように扱う「対象の算術」で、終対象が掛け算の単位になるから：

| 圏の構成 | `0`(始対象) | `1`(終対象) | `A+B` | `A×B` | `Bᴬ` |
|---|---|---|---|---|---|
| Set の要素数 | 0 | 1 | 和 | 積 | べき |

`A × 1 ≅ A`（⟷ `a×1=a`）。`(0,1,+,×,\exp)` が半環の算術を再現するので `1` は `0,+,×` と整合した命名。気まぐれではない。

使い分け：算術対応・圏論の文脈 → `1`、役割・PL 的 → 単位型/unit、論理 → `⊤`。すべて同じ対象の別の顔。
